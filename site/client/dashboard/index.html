download crypto client 0.54.1
  1. Download crypto-client-0.54.1.zip and unzip it anywhere.
  2. Start VRChat from Steam and wait for the main menu.
  3. Run bash crypto-client-0.54.1/launch.sh in a terminal.
  4. In VRChat press Insert → License (key icon) → paste your key → Activate.

Needs Linux with Steam installed as a Flatpak.
